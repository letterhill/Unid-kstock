# Unid-Battery

센서 데이터와 열화상 이미지를 활용하여  
**배터리 열폭주 조기 예측 가능성**을 검토하는 Uni-D 데이터톤팀 미니프로젝트입니다.

본 프로젝트는 최종 데이터톤 주제를 선정하기 전, AI-Hub의 배터리 열폭주 멀티모달 데이터가 실제 프로젝트에 적합한지 확인하기 위해 2주간 진행합니다.

---

## 1. 프로젝트 개요

### 프로젝트명

멀티모달 데이터 기반 배터리 열폭주 조기 예측

### 데이터셋

- 제공 기관: AI-Hub
- 데이터명: 배터리 열폭주 제어 멀티모달 데이터
- 활용 데이터
  - 센서 데이터 JSON
  - 열화상 이미지 PNG
  - 열폭주 단계 및 상태 라벨 JSON
- 초기 분석은 AI-Hub 샘플데이터를 기준으로 진행
- 필요 시 선택한 실험 조건의 원본 데이터로 확장

> AI-Hub 원본 데이터와 압축파일은 GitHub에 업로드하지 않습니다.  
> 데이터는 팀 Google Drive에서 별도로 관리합니다.

---

## 2. 프로젝트 목표

본 프로젝트의 최종 목표는 높은 모델 성능을 달성하는 것이 아니라, 다음 항목을 검토하여 해당 데이터셋의 **최종 데이터톤 주제 활용 가능성**을 판단하는 것입니다.

1. 센서 데이터와 열화상 이미지를 시간 기준으로 연결할 수 있는지 확인
2. 열폭주 단계 및 상태 라벨이 모델 학습에 활용 가능한지 확인
3. 열폭주 이전 구간이 충분히 존재하는지 확인
4. 열폭주 발생 10초, 30초, 60초 전 예측 라벨을 구성할 수 있는지 확인
5. 센서 단독 모델과 멀티모달 모델의 성능을 비교
6. 서로 다른 실험에서도 전조 패턴이 반복되는지 확인
7. 라벨 및 센서 변수에 정답 누수가 존재하는지 확인
8. 최종 데이터톤 주제로 발전시킬 가치가 있는지 판단

### 예상 문제 정의

데이터 분석 결과에 따라 다음 중 하나로 최종 문제를 정의합니다.

- 열폭주 조기 예측
- 일정 시간 이내 열폭주 발생 여부 예측
- 열폭주 위험도 분류
- 열폭주 진행 단계 분류

열폭주 이전 데이터가 충분하지 않은 경우, **조기 예측** 대신 **단계 분류 또는 위험도 탐지**로 주제를 조정할 수 있습니다.

## 5. 단계별 작업 계획

### 5.1 데이터 분석 및 EDA

- 전체 파일 및 폴더 구조 확인
- 이미지, 센서 JSON, 라벨 JSON 개수 확인
- 센서 JSON과 라벨 JSON의 필드 구조 확인
- 실험 ID별 데이터 구성 확인
- Training과 Validation의 실험 ID 중복 확인
- 센서와 라벨 파일 매칭률 확인
- 센서와 열화상 이미지의 시간 정렬 가능성 확인
- 열폭주 단계별 데이터 분포 확인
- 주요 센서 변수의 시계열 변화 시각화
- 열폭주 이전 구간의 길이 확인
- 이미지 품질, 해상도 및 손상 여부 확인
- 이상 상태 변수 및 라벨 누수 가능성 확인
- 조기 예측 문제 구성 가능 여부 판단

### 5.2 데이터 전처리

- 원천 센서 JSON과 라벨 JSON 병합
- 센서 데이터와 열화상 이미지 매칭
- 시간 및 프레임 번호 정렬
- 결측치와 이상치 처리
- 주요 센서 변수 선택
- 센서 변화량, 이동 평균, 기울기 등 파생 변수 생성
- 열화상 이미지 크기 및 형식 통일
- 조기 예측용 미래 라벨 생성
- 실험 ID 기준 Train, Validation, Test 분리
- 모델링 담당자에게 최종 데이터와 사용 방법 전달

### 5.3 모델링

#### 센서 단독 모델

- Logistic Regression
- Random Forest
- XGBoost 또는 LightGBM

#### 이미지 단독 모델

- ResNet18 등 경량 CNN 기반 모델

#### 멀티모달 모델

- 이미지 임베딩과 센서 특징 결합
- 결합 특징을 MLP에 입력하여 분류

#### 평가 지표

- Accuracy
- Macro F1-score
- 클래스별 Recall
- Confusion Matrix
- 조기 경보 시점

클래스 불균형이 예상되므로 Accuracy만 사용하지 않고 Macro F1과 클래스별 Recall을 함께 확인합니다.

따라서 데이터는 반드시 **실험 ID 기준으로 분할**합니다.

```text
잘못된 방법
전체 프레임을 무작위로 Train/Test 분할

권장 방법
실험 ID 단위로 Train/Test 분할
