# Uni-D K-스톡 콘텐츠 데이터 미니 프로젝트

## 1. 프로젝트 개요

본 프로젝트는 **Uni-D 데이터톤 최종 주제 선정을 위한 사전 미니 프로젝트**입니다.

AI Hub의 **K-스톡 콘텐츠 데이터**를 분석하고 간단한 전처리 및 모델링 실험을 진행하여, 해당 데이터가 데이터톤 문제로 활용하기에 적절한지 검토합니다.

최종 주제 선정 이전 단계인 만큼 대규모 학습이나 복잡한 모델 개발보다는 다음 항목을 빠르게 확인하는 데 목적이 있습니다.

- 데이터 구조와 품질
- 이미지와 캡션·분류 라벨의 관계
- 프로그램·키워드·분류별 데이터 편중
- 이미지와 텍스트 간 의미적 일치도
- 데이터 누출 가능성
- 데이터톤 태스크 구성 가능성
- 간단한 베이스라인의 구현 및 평가 가능성

최종 주제로 선정될 경우, 미니 프로젝트 결과를 바탕으로 추가 2주간 고도화를 진행하는 방안을 고려합니다.

BASE_DIR = "/content/drive/MyDrive/..."

## 3. 프로젝트 목표

### 3.1 데이터 분석

- 이미지와 JSON 파일 수 및 연결 상태 확인

## 9. GitHub 업로드 방법

이번 미니 프로젝트에서는 복잡한 브랜치 작업 없이 **각자 다른 파일명으로 `main` 브랜치에 직접 업로드**합니다.

### 9.1 Colab 노트북 내려받기

Colab 메뉴에서 다음 순서로 진행합니다.

```text
파일 → 다운로드 → .ipynb 다운로드
```

노트북을 업로드하기 전 다음 내용을 확인합니다.

- 코드가 위에서부터 순서대로 실행되는지
- 주요 실행 결과가 남아 있는지
- 오류가 발생한 임시 셀은 정리했는지
- 개인 Google Drive 경로가 어디인지 설명되어 있는지
- 원본 데이터가 노트북 내부에 포함되지 않았는지

### 9.2 GitHub 웹에서 업로드하기

1. 프로젝트 GitHub Repository에 접속합니다.
2. 업로드할 폴더로 이동합니다.
   - 노트북: `notebooks/`
   - 문서: `docs/`
   - 샘플 결과: `outputs/sample_results/`
3. 우측 상단의 `Add file`을 클릭합니다.
4. `Upload files`를 선택합니다.
5. 파일을 드래그하거나 `choose your files`를 클릭합니다.
6. Commit message를 작성합니다.
7. `Commit changes`를 클릭합니다.

### 9.3 Commit message 예시

```text
Add K-Stock data analysis
Update K-Stock preprocessing notebook
Add CLIP baseline experiment
Fix image-label matching
Add modeling result summary
```

한 번에 여러 작업을 섞기보다, 어떤 내용을 추가하거나 수정했는지 알 수 있도록 작성합니다.
